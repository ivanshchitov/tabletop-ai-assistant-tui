# Tabletop AI Assistant

Консольный TUI-ассистент по настольным играм. Отвечает на вопросы о правилах, спорных ситуациях, стратегиях и рекомендациях по настольным играм с помощью модели `deepseek-v4-flash`, а вопросы не по теме вежливо отклоняет с объяснением причины. Ответы рендерятся как Markdown с эффектом постепенной печати, история диалога сохраняется между запусками.

## Технические требования

- Python 3.9+
- Зависимости из `requirements.txt`: `rich`, `requests`, `python-dotenv`
- API-ключ в переменной окружения `OPENCODE_API_KEY` (задаётся в `.env`, см. `.env.example`) — используется для доступа к модели `deepseek-v4-flash` через эндпоинт OpenCode Zen `https://opencode.ai/zen/v1/chat/completions`
- Терминал с поддержкой ANSI-цветов и Unicode/emoji
- Интернет-соединение для обращения к API

Установка зависимостей и запуск:

```bash
pip install -r requirements.txt
echo "OPENCODE_API_KEY=sk-ваш_ключ" > .env
python tabletop-ai-assistant.py
```

Единственная команда в приложении — `/exit` (с автодополнением по Tab), выход завершает работу и сохраняет историю в `history.json`.

## Сценарии использования

- **Правила игры**: «Подскажи правила игры "Каркассон"» — получить структурированное описание подготовки, хода и подсчёта очков.
- **Спорная ситуация за столом**: «Можно ли ставить мипла на монастырь, если он уже занят?» — разрешение спорного момента со ссылкой на логику правил.
- **Подбор игры**: «Что купить на 4 игроков для вечеринки?» — рекомендация с уточнением количества игроков, сложности и жанра.
- **История и контекст игры**: «Откуда взялась игра "Диксит"?» — краткая справка по происхождению и особенностям игры.
- **Вопрос не по теме**: «Какая сегодня погода?» — ассистент объясняет, что работает только с настольными играми, и предлагает переформулировать вопрос.
