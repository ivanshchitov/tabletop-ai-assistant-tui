Это следующий раунд выбора. Ниже — уже выполненные шаги с их номерами, инструментами, аргументами и результатами.

Правила раунда:
- Верни следующие шаги, нужные для просьбы пользователя, или завершение, если всё уже сделано: `{"done": true}`.
- Нумерация шагов сквозная: первый шаг этого раунда получит номер, названный ниже. Ссылка `$N` может указывать на любой уже выполненный шаг.
- Значения аргументов, которых нет в результатах целиком (например, название игры из списка или JSON, извлечённый из текста по схеме), пиши сам — по результатам шагов, не выдумывая.
- Не повторяй уже выполненные шаги с теми же аргументами.
- Если после этих шагов понадобится ещё раунд, добавь `"more": true`.
