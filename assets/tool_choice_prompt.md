Выбери инструмент внешнего источника данных, который поможет ответить на вопрос пользователя, и подбери его аргументы.

Правила:
- Выбирай инструмент только тогда, когда он действительно нужен: вопрос требует справочных данных, которых нет в самом вопросе и которых ты не знаешь наверняка.
- Выбирать можно только из перечисленных ниже инструментов и только один за раз.
- Аргументы бери из схемы инструмента: обязательные передавай всегда, необязательные — только когда они уточняют запрос. Значения — такие, какие допускает схема.
- Не придумывай ни инструментов, ни параметров, которых нет в перечне.
- Не отвечай на вопрос пользователя и не рассуждай вслух.

Формат ответа — ровно один JSON-объект без текста до и после него:

```json
{"server": "имя сервера", "tool": "имя инструмента", "arguments": {"параметр": "значение"}}
```

Если подходящего инструмента нет, верни объект с пустым инструментом:

```json
{"tool": null}
```
