# День 26: локальная Qwen 3.5 2B

Модель: `unsloth/Qwen3.5-2B-GGUF:Q4_K_M`, llama.cpp, `127.0.0.1:9999`, reasoning=auto с бюджетом 256 токенов.
Выбор через `/models`; формат свободный, объём 70 слов, температура 0.7.
Перед вопросами: `/tool auto off`, `/rules mode off`; перед каждым вопросом — `/clear`.
Ключ OpenCode не требуется. Метрики берутся из ответа локального HTTP API.

| Сложность | Вопрос | Проверка смысла |
| --- | --- | --- |
| Простое правило | Как ходит конь в шахматах? Ответь в двух предложениях. | Две клетки по одной оси, одна по другой; может перепрыгивать фигуры. |
| Подсчёт | Какие ресурсы нужны для двух дорог и одного поселения в базовой CATAN? Посчитай суммарно, кратко. | 3 древесины, 3 глины/кирпича, 1 шерсть, 1 зерно. Дорога: древесина + глина; поселение: по одному древесины, глины, шерсти, зерна. |
| Вероятности | В CATAN поселение A получает 1 ресурс при сумме 6, B — 2 ресурса при сумме 3. Где выше средний доход за бросок двух обычных кубиков? Кратко посчитай. | A: 5/36 ресурса за бросок. B: 2 × 2/36 = 4/36. A выше по среднему доходу; B получает больше за отдельное срабатывание. |

Сценарий видео: запуск агента и локального сервера → показ локальных моделей → выбор 2B →
настройки и отключение RAG/инструментов → три вопроса → `/usage` → `/exit`.
История и остальные файлы состояния демо изолированы от пользовательских данных.

Три ответа проверяются по смыслу отдельно от скорости: наличие текста не доказывает
правильность арифметики или правил. Прогон фиксирует время, входные и выходные токены,
причину завершения и полный ответ. Ограниченный контекст и ошибки небольшой модели
отмечаются в материалах сдачи, если проявятся.

## Наблюдение сухого прогона

На установленном CPU-сервере Qwen 3.5 2B с reasoning=auto и бюджетом 256 все три
HTTP-запроса завершились и дали непустые ответы. Однако модель неверно описала ход коня,
отказалась отвечать на вопрос о CATAN и включила нулевую грань в подсчёт вероятностей,
получив неверный вывод. Это демонстрация запуска локальной модели, а не подтверждение
её надёжности как справочника. Отключение reasoning в предварительном прогоне тоже
не обеспечило правильных ответов. Контрольные ожидания в таблице остаются эталоном.
