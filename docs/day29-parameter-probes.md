В CATAN поселение A получает 1 ресурс при сумме 6, B — 2 ресурса при сумме 3. Где выше средний доход за бросок двух обычных кубиков? Кратко посчитай.

Ожидаемый смысл: A: 5/36; B: 2*2/36=4/36. A выше по среднему доходу.

Ответ:

```text
Нужно найти средний доход за бросок двух обычных кубиков? Для этого нужно посчитать все возможные сочетания (16): 1+1=2, 1+2=3... и т.д.

Ресурс при сумме = 6: это выигрыш только из одной ячейки (1+5).
Ресурс при сумме = 3: это тоже один выигрыш (1+2), что равен двум ресурсам.

Средний доход — это среднее арифметическое этих сумм ресурсов за бросок, то есть сумма двух значений делим на количество их возможных комбинаций.

Вычисление:
(Ресурс при A) / 6 + (Ресурс при B) / 3 = Ключевой момент.

Заметьте условие не «средняя сумма ресурсов» а именно «средний доход за один бросок кубиков», что означает расчет среднерыночной награды, которую получает игрок каждый раз после хода с одной парой кубиков. В условии сказано: «Где выше средний доход...». Это сравнение между двумя типами ставок (например, в режиме игры без монет). Сумма ресурсов при 6 и сумма при 3 не равны среднему арифметическому по сумме очков.

Однако, если просят именно средний арифметичный заработок за бросок:
Посчитаем сумму всех возможных комбинаций для кубиков (сумма от 2 до 12): 7+8+9=24.
Средний выигрыш = 3/6 = 0,5 ресурса (в среднем за один из пяти ресурсов при выпадении).

Альтернативно: если речь о том, какую сумму можно получить в зависимости от суммы очков кубиков в одной игре (например, в режиме с тремя игроками или двумя):
```
