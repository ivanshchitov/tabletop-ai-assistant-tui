## Why

В реестре лежат три MCP-сервера по теме настольных игр, но приложение подключается только к одному — выбранному по умолчанию; остальные записи мертвы до тех пор, пока кто-то не поменяет умолчание в коде. При этом соединение поднимается лениво, по команде, так что пользователь узнаёт о доступных инструментах только когда сам спросит — и каждый раз ждёт запуска процесса. Подключение всех серверов при запуске делает набор инструментов известным с первой секунды сессии и превращает `/mcp` в мгновенный отчёт.

## What Changes

- При запуске приложение SHALL подключаться ко **всем** серверам реестра, а не к одному: рукопожатие и список инструментов снимаются с каждого.
- Подключение происходит до первого приглашения ввода, с индикацией ожидания; по его завершении печатается короткая строка итога — сколько серверов поднялось и сколько инструментов они дают.
- Сбой любого сервера не мешает ни остальным серверам, ни запуску приложения: его причина попадает в снимок и в отчёт.
- `/mcp` печатает отчёт по всем серверам из снимка, снятого при запуске: мгновенно, без единого нового процесса.
- **BREAKING**: у `/mcp` появляется значимый аргумент `refresh` — он переподключается ко всем серверам заново и обновляет снимок. Раньше аргументы команды игнорировались.
- Переопределение `TABLETOP_MCP_COMMAND`/`TABLETOP_MCP_ARGS` заменяет **весь** реестр одной записью, а не только запись по умолчанию: иначе автоматический прогон поднимал бы все настоящие серверы из сети.

### Modified Capabilities
- `mcp-integration`: соединение поднимается не с одним сервером, а со всеми записями реестра; снимок отчёта становится набором снимков; переопределение окружением заменяет реестр целиком.
- `terminal-ui`: подключение при запуске со строкой итога, отчёт `/mcp` по всем серверам из снимка и значимый аргумент `refresh`.
- `configuration`: переменные `TABLETOP_MCP_COMMAND`/`TABLETOP_MCP_ARGS` описываются как замена всего реестра.
- `test-infrastructure`: изоляция прогона требует, чтобы ни один сервер реестра не поднимался — при запуске в том числе.

## Impact

- `core/config.py`: разрешение реестра с учётом переопределения (`mcp_servers()` вместо одиночного `mcp_server_spec()`).
- `core/tabletop_agent.py`: подключение ко всем записям, хранение снимка, обновление по запросу.
- `ui/tui_app.py`: подключение при старте со спиннером и строкой итога, отчёт по нескольким серверам, разбор аргумента `refresh`.
- Тесты: юниты агента и интерфейса, e2e-сценарий старта и `/mcp`, снапшоты стартового экрана.
- Время запуска приложения растёт на время подключения (в реальной конфигурации — секунды; в тестах реестр подменён одним локальным сервером).
