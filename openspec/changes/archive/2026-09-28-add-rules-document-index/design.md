## Context

Приложение — Python TUI, которое передаёт вопросы модели через Chat Completions API. Сейчас источники ответов не хранятся. Корпус будет состоять из PDF в `docs/rules/`; приложение не должно индексировать их при старте.

## Goals / Non-Goals

**Goals:**
- Локально извлекать текст и строить воспроизводимый индекс документов.
- Поддержать фиксированное и структурное разбиение, метаданные и сравнение результатов.
- Подмешивать найденные фрагменты к вопросу об игровых правилах и отображать источники.

**Non-Goals:**
- Автоматическое скачивание или обновление документов при запуске.
- Облачное хранилище и отдельный векторный сервер.
- Индексация произвольных форматов за пределами PDF в этом изменении.

## Decisions

- Извлечение текста выполнять библиотекой Python для PDF, чтобы команда работала без внешних исполняемых программ.
- Хранить корпусные фрагменты, сериализованные векторы и метаданные в SQLite — без отдельного сервера и с возможностью атомарно пересобрать индекс.
- Строить локальные нормализованные векторные представления из слов и символьных n-грамм фиксированного размера; искать косинусной близостью. Это не требует сетевого вызова или отдельной модели эмбеддингов и даёт воспроизводимый локальный результат.
- Сравнение стратегий выполняется для одного и того же набора документов и поискового запроса: экран показывает число чанков, диапазон размеров и найденные источники.
- Для структурного разбиения использовать заголовки/разделы PDF и границы файлов; при отсутствии заголовков делить файл по фиксированному пределу.
- Команда `/rules index` строит индекс явно. Обычный вопрос использует существующий индекс, если он доступен; пустой индекс не меняет прежнее поведение.
- Пути корпуса и базы индекса настраиваются переменными окружения, чтобы тесты не меняли файлы проекта.

## Risks / Trade-offs

- Локальные хешированные векторы легче и надёжнее внешнего embedding API, но хуже распознают семантические перефразировки.
- PDF с таблицами или необычной версткой может извлекаться с потерями; корпус и извлечённый объём нужно проверить до индексации.
- Для части игр опубликованные издателем правила могут иметь ограничения распространения; в каталоге нужно сохранять источник и сведения об условиях использования.
