## Why

Помощник отвечает на вопросы о настольных играх, но не может показать, на какие конкретные правила опирается ответ. Индекс локальных документов даст ответы с проверяемыми фрагментами и позволит наглядно сравнить способы разбиения текста.

## What Changes

- В репозитории появится каталог `docs/rules/` с официальными правилами Dungeons & Dragons SRD, CATAN и Ticket to Ride.
- Команда `/rules index` будет извлекать текст PDF, строить локальный индекс с эмбеддингами и метаданными. При запуске приложения индексация не выполняется.
- Команда `/rules compare` покажет результаты фиксированного и структурного разбиения на одном корпусе и запросе.
- Обычный вопрос о правилах будет дополнен наиболее релевантными фрагментами готового индекса; ответ покажет источники.

### New Capabilities
- `rules-document-index`: локальная индексация, поиск по правилам игр, происхождение фрагментов и сравнение разбиения.

### Modified Capabilities

## Impact

- Новые модули корпуса и индекса в `core/`, обработка команд и вывода источников в `ui/tui_app.py`, команда в панели `ui/commands_screen.py`.
- Зависимость для чтения PDF, тесты юнит- и сценарного уровней, документы правил в `docs/rules/`.
- Индекс хранится отдельно локальным файлом; добавляются настройки путей для тестовой изоляции.
- Для вопросов без найденного индекса или релевантного фрагмента сохраняется текущее поведение помощника.

## Acceptance Criteria

- «Возьмите набор документов:
  - README / статьи / код / pdf → текст
  - минимум 20–30 страниц текста суммарно (или эквивалент в коде)»
- «Реализуйте пайплайн индексации:
  - разбиение на чанки (chunking)
  - генерация эмбеддингов
  - сохранение индекса (FAISS / SQLite / JSON)»
- «Усиление:
  - добавьте метаданные к каждому чанку (source, title/file, section, chunk_id)
  - сделайте минимум 2 стратегии chunking и сравните их:
    - по фиксированному размеру
    - по структуре (заголовки/разделы/файлы)»
- «Локальный индекс документов с эмбеддингами + метаданные + сравнение 2 стратегий chunking»
- Демо: построить индекс командой `/rules index`, задать вопрос по правилам и увидеть источники ответа, затем сравнить стратегии разбиения.
