## MODIFIED Requirements

### Requirement: Переменные переопределения поведения
Следующие переменные SHALL переопределять значения по умолчанию, сохраняя работоспособность
приложения при полном их отсутствии:
- `OPENCODE_API_URL` — адрес эндпоинта (по умолчанию `https://opencode.ai/zen/v1/chat/completions`);
- `TABLETOP_HISTORY_FILE` — путь к файлу истории диалога (по умолчанию `history.json` в корне репозитория);
- `TABLETOP_MEMORY_FILE` — путь к файлу долговременной памяти (по умолчанию `memory.json` в корне репозитория);
- `TABLETOP_PROFILE_FILE` — путь к файлу профилей пользователя (по умолчанию `profile.json` в корне репозитория);
- `TABLETOP_TASK_FILE` — путь к файлу состояния задачи (по умолчанию `task.json` в корне репозитория);
- `TABLETOP_TASKS_DIR` — каталог результатов задач (по умолчанию `tasks/` в корне репозитория);
- `TABLETOP_REQUEST_TIMEOUT` — таймаут HTTP-запроса в секундах (по умолчанию 90);
- `TABLETOP_TYPING_DELAY` — пауза между кадрами анимации печати в секундах (по умолчанию 0.015);
- `TABLETOP_COMPRESS_AFTER` — порог сжатия контекста в сообщениях (по умолчанию 10);
- `TABLETOP_MAX_SESSION_TOKENS` — потолок токенов собираемого запроса сессии (по умолчанию 20000);
- `TABLETOP_MCP_COMMAND` — команда запуска MCP-сервера; заданная, она заменяет весь реестр серверов
  единственной записью (по умолчанию используется реестр целиком);
- `TABLETOP_MCP_ARGS` — аргументы команды запуска MCP-сервера, разделённые пробелами (относятся к той
  же единственной записи);
- `TABLETOP_DND_API_URL` — базовый адрес внешнего API, к которому обращается собственный MCP-сервер
  проекта (по умолчанию публичный адрес этого API);
- `TABLETOP_AUTO_TOOLS` — начальное состояние автоматического вызова инструмента (по умолчанию
  включён); выключенным значением сессия начинается без автовызова.

#### Scenario: Адрес эндпоинта переопределён
- **WHEN** задана `OPENCODE_API_URL`, указывающая на локальный сервер
- **THEN** все запросы к модели уходят на указанный адрес

#### Scenario: Таймаут переопределён
- **WHEN** задана `TABLETOP_REQUEST_TIMEOUT=1`
- **THEN** HTTP-клиент использует таймаут 1 секунда

#### Scenario: Анимация свёрнута
- **WHEN** задана `TABLETOP_TYPING_DELAY=0`
- **THEN** ответ выводится практически мгновенно, без ощутимой анимации

#### Scenario: Таймаут по умолчанию покрывает медленную генерацию reasoning-моделей
- **WHEN** `TABLETOP_REQUEST_TIMEOUT` не задана и модель генерирует развёрнутый ответ дольше 30 секунд
- **THEN** запрос не обрывается по таймауту раньше 90 секунд

#### Scenario: Лимит истории переопределён
- **WHEN** задана `TABLETOP_HISTORY_LIMIT` (переменная бывшего лимита записей истории)
- **THEN** переменная игнорируется: глубина контекста сессии задаётся порогом сжатия и потолком токенов, а файл истории не ограничен

#### Scenario: Порог сжатия переопределён
- **WHEN** задана `TABLETOP_COMPRESS_AFTER=5`
- **THEN** порог сжатия по умолчанию равен 5 сообщениям

#### Scenario: Потолок токенов переопределён
- **WHEN** задана `TABLETOP_MAX_SESSION_TOKENS=6000`
- **THEN** потолок контекста сессии по умолчанию равен 6000 токенов

#### Scenario: Путь долговременной памяти переопределён
- **WHEN** задана `TABLETOP_MEMORY_FILE`, указывающая на другой файл
- **THEN** долговременная память читается и пишется в указанный файл, а `memory.json` в корне репозитория не трогается

#### Scenario: Переменной нет — память работает
- **WHEN** `TABLETOP_MEMORY_FILE` не задана
- **THEN** путь по умолчанию выводится из расположения кода приложения, долговременная память читается и пишется без ошибок

#### Scenario: Путь файла профилей переопределён
- **WHEN** задана `TABLETOP_PROFILE_FILE`, указывающая на другой файл
- **THEN** профили читаются и пишутся в указанный файл, а `profile.json` в корне репозитория не трогается

#### Scenario: Переменной профилей нет — профиль работает
- **WHEN** `TABLETOP_PROFILE_FILE` не задана
- **THEN** путь по умолчанию выводится из расположения кода приложения, профили читаются и пишутся без ошибок

#### Scenario: Каталог результатов задач переопределён
- **WHEN** задана `TABLETOP_TASKS_DIR`, указывающая на другой каталог
- **THEN** результаты задач пишутся в него, а `tasks/` в корне репозитория не трогается

#### Scenario: Путь файла состояния задачи переопределён
- **WHEN** задана `TABLETOP_TASK_FILE`, указывающая на другой файл
- **THEN** очередь задач читается и пишется в указанный файл, а `task.json` в корне репозитория не трогается

#### Scenario: Переменной задач нет — очередь работает
- **WHEN** `TABLETOP_TASK_FILE` не задана
- **THEN** путь по умолчанию выводится из расположения кода приложения, очередь задач читается и пишется без ошибок

#### Scenario: Команда запуска MCP-сервера переопределена
- **WHEN** заданы `TABLETOP_MCP_COMMAND` и `TABLETOP_MCP_ARGS`, указывающие на локальный сервер
- **THEN** подключение поднимает ровно один этот сервер, а записи реестра не используются

#### Scenario: Переменных MCP нет — работает сервер по умолчанию
- **WHEN** `TABLETOP_MCP_COMMAND` и `TABLETOP_MCP_ARGS` не заданы
- **THEN** подключение поднимает серверы реестра, включая выбранный по умолчанию


#### Scenario: Адрес внешнего API своего сервера переопределён
- **WHEN** задана `TABLETOP_DND_API_URL`, указывающая на локальную заглушку
- **THEN** собственный MCP-сервер проекта обращается к ней, а публичный адрес по умолчанию не используется

#### Scenario: Переменной внешнего API нет — сервер работает
- **WHEN** `TABLETOP_DND_API_URL` не задана
- **THEN** собственный MCP-сервер проекта обращается к публичному адресу по умолчанию

#### Scenario: Автовызов выключен переменной
- **WHEN** задана `TABLETOP_AUTO_TOOLS=0`
- **THEN** сессия начинается с выключенным автовызовом: вспомогательный запрос выбора инструмента перед вопросом не отправляется, пока его не включат командой

#### Scenario: Переменной автовызова нет — автовызов включён
- **WHEN** `TABLETOP_AUTO_TOOLS` не задана
- **THEN** сессия начинается с включённым автовызовом
