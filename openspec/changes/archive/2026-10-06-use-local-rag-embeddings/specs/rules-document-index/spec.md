## MODIFIED Requirements

### Requirement: Команды индекса правил
Команда `/rules` SHALL показывать состояние индекса, состояние режима RAG, режим поиска и его параметры и доступные подкоманды. `/rules index` SHALL создавать индекс; `/rules compare <запрос>` SHALL сравнивать стратегии разбиения без изменения сохранённых текстов и хеш-векторов индекса, с возможностью сохранения недостающих локальных embedding-векторов; `/rules mode on|off` SHALL переключать использование индекса для следующих вопросов в текущей сессии. `/rules retrieval baseline|enhanced`, `/rules tune before=<K> after=<K> threshold=<T>` и `/rules trace` SHALL управлять поиском и показывать его результаты согласно спецификации `rules-retrieval`. При запуске нового сеанса режим RAG SHALL быть включён и SHALL использовать `enhanced` с настройками по умолчанию. Эти команды SHALL NOT отправлять запрос модели чата; при выбранной локальной модели `/rules index` и `/rules compare` SHALL использовать локальный embedding API. Команды SHALL NOT попадать в историю диалога; вспомогательные запросы улучшенного поиска SHALL выполняться только при обработке вопроса.

#### Scenario: Справка команды
- **WHEN** пользователь вводит `/rules` без подкоманды
- **THEN** приложение показывает состояние индекса, состояние режима RAG, режим поиска, параметры и синтаксис доступных команд

#### Scenario: Команды не используют API модели
- **WHEN** пользователь запускает `/rules index` или `/rules compare <запрос>`
- **THEN** ни одного запроса к модели чата не выполняется; при локальной модели допускаются запросы к embedding API

#### Scenario: Переключить режим
- **WHEN** пользователь вводит `/rules mode off` или `/rules mode on`
- **THEN** приложение подтверждает выбранный режим для следующих вопросов без обращения к модели

#### Scenario: Неверный режим
- **WHEN** пользователь вводит `/rules mode` без `on|off` или с иным значением
- **THEN** приложение показывает правильный синтаксис и сохраняет текущий режим
