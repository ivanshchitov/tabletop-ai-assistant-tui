## MODIFIED Requirements

### Requirement: Команда /models открывает панель выбора модели
Приложение SHALL поддерживать команду `/models`, открывающую интерактивную панель со списком всех доступных моделей. Список SHALL состоять ровно из моделей: `deepseek-v4-flash`, `deepseek-v4-pro`, `kimi-k2.5`, `glm-5.1`, `mimo-v2.5-free`, `minimax-m2.5`, `kimi-k3`. Управление панелью: ↑/↓ — перемещение курсора, Enter — применить выбранную модель, Esc — отменить выбор. Панель SHALL NOT выполнять API-вызовов: выбор меняет только локальное состояние сессии. Курсор при открытии панели SHALL стоять на текущей модели, а текущая модель SHALL быть визуально помечена в списке. Команда SHALL быть доступна и через ручной ввод с автодополнением, и через панель `/commands` (единый список команд).

#### Scenario: Панель открыта, курсор на текущей модели
- **WHEN** пользователь вводит `/models` при активной модели `deepseek-v4-flash`
- **THEN** открывается панель со списком семи моделей, курсор стоит на `deepseek-v4-flash`, и модель помечена как текущая

#### Scenario: Выбор модели по Enter
- **WHEN** курсор стоит на `kimi-k2.5` и пользователь нажимает Enter
- **THEN** панель закрывается, `kimi-k2.5` становится активной моделью сессии

#### Scenario: Отмена по Esc
- **WHEN** панель открыта, курсор перемещён на другую модель и пользователь нажимает Esc
- **THEN** панель закрывается, активная модель остаётся прежней, ни одного запроса к API не отправлено

#### Scenario: Запуск из панели /commands
- **WHEN** в панели `/commands` пользователь выбирает строку `/models` и нажимает Enter
- **THEN** открывается панель выбора модели

#### Scenario: Автодополнение команды
- **WHEN** пользователь набирает `/mo` и нажимает Tab
- **THEN** ввод дополняется до `/models`

#### Scenario: Новые модели тира сравнения доступны
- **WHEN** пользователь открывает `/models`
- **THEN** в списке присутствуют `minimax-m2.5` и `kimi-k3` наряду с ранее доступными моделями

## ADDED Requirements

### Requirement: Таблица цен покрывает все доступные модели
Для каждой модели из списка `/models` SHALL существовать цена входных и выходных токенов (за 1 млн токенов), используемая для расчёта стоимости запроса. Модель без цены в таблице SHALL считаться моделью с неизвестной стоимостью — расчёт стоимости для неё SHALL возвращать отсутствие значения, а не ошибку.

#### Scenario: Цена известна
- **WHEN** запрашивается цена для `deepseek-v4-flash`
- **THEN** возвращается пара цен «вход/выход» за 1 млн токенов

#### Scenario: Модель без цены в таблице
- **WHEN** запрашивается цена для модели, отсутствующей в таблице цен
- **THEN** результат — отсутствие значения (не ошибка)
