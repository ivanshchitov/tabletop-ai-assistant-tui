## ADDED Requirements

### Requirement: Доп.-информация после каждого запроса прогона
После каждого фактического запроса к API внутри `/logictask` приложение SHALL печатать на экран строку с временем ответа, количеством токенов и стоимостью этого конкретного запроса — отдельно на каждый вызов, не агрегатом по всей стратегии. Для стратегии 3 (промпт от модели) строка SHALL печататься дважды (после составления промпта и после решения по нему); для стратегии 4 (панель экспертов) — трижды, по одной после ответа каждого эксперта.

#### Scenario: Стратегия 1 — одна строка доп.-информации
- **WHEN** выбрана стратегия «прямой ответ» и запрос завершился
- **THEN** под ответом видна одна строка со временем, токенами и стоимостью этого запроса

#### Scenario: Стратегия 3 — две строки доп.-информации
- **WHEN** выбрана стратегия «промпт от модели»
- **THEN** на экране видны две строки доп.-информации: одна после составленного промпта, одна после итогового ответа

#### Scenario: Стратегия 4 — три строки доп.-информации
- **WHEN** выбрана стратегия «панель экспертов»
- **THEN** на экране видны три строки доп.-информации, по одной после ответа каждого эксперта
