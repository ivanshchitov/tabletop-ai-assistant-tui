## ADDED Requirements

### Requirement: Метрики использования запроса
Клиент SHALL предоставлять способ получить вместе с текстом ответа: время ответа (от отправки запроса до получения ответа), количество входных, выходных и суммарных токенов (из поля `usage` ответа API), и стоимость запроса, рассчитанную по таблице цен для использованной модели. Стоимость SHALL отсутствовать (не быть рассчитанной), если для модели нет цены в таблице, без ошибки. Существующий способ получить только текст ответа SHALL продолжать работать без изменений в поведении.

#### Scenario: Метрики известной модели
- **WHEN** вопрос отправлен с моделью, у которой есть цена в таблице
- **THEN** вместе с ответом доступны время ответа, количество токенов и рассчитанная стоимость

#### Scenario: Метрики модели без цены
- **WHEN** вопрос отправлен с моделью без цены в таблице
- **THEN** вместе с ответом доступны время ответа и токены, а стоимость отсутствует, ошибки не возникает

#### Scenario: Существующий способ получения ответа не меняется
- **WHEN** используется прежний способ получить только текст ответа
- **THEN** поведение (форма запроса, ретраи, обработка ошибок) не отличается от текущего
