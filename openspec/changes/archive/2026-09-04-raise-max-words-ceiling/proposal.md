## Why

При записи демо для дня 5 (сравнение слабой/средней/сильной модели на одном сложном вопросе,
требующем развёрнутого обоснования) несколько моделей из пула OpenCode Zen (`kimi-k2.5`,
`kimi-k2.6`, `glm-5.1`, `deepseek-v4-pro`) — reasoning-модели, отдающие рассуждение в отдельное
поле `reasoning_content` перед `content`. На сложном сравнительном вопросе рассуждение съедает
весь технический потолок `max_tokens` (850 при текущем максимуме настройки в 500 слов), и модель
обрывается по `finish_reason: "length"` до того, как успевает написать сам ответ — пользователь
получает пустой `content`, хотя усечения по ошибке или сбоя API не было. Прямая проверка через API
показала: `kimi-k2.6` уверенно отвечает на этот же вопрос при `max_tokens=4000` (эквивалент ~988
слов). Текущий потолок настройки `/settings` (10..500 слов) не даёт пользователю такой запас.

## What Changes

- Верхняя граница настройки объёма ответа (`core/config.MAX_MAX_WORDS`) поднимается с 500 до 1000
  слов — соответствующий технический потолок `max_tokens` при значении 1000 слов равен 4050,
  достаточно для reasoning-моделей на развёрнутых вопросах, требующих обоснования.
  Значение по умолчанию (200 слов) и нижняя граница (10 слов) не меняются.
- Экран `/settings` и вспомогательные тексты (README, CLAUDE.md), где фигурирует диапазон
  10..500, отражают новый диапазон 10..1000.

## Capabilities

### New Capabilities

_(нет)_

### Modified Capabilities

- `answer-settings`: верхняя граница диапазона объёма ответа увеличивается с 500 до 1000 слов.
- `configuration`: константа `MAX_MAX_WORDS` в описании поведенческих констант — с 500 до 1000;
  заодно актуализируется список моделей в том же требовании (был зафиксирован до добавления
  `minimax-m2.5`→`kimi-k2.6`/`kimi-k3` в прошлом изменении и с тех пор не синхронизировался).
- `settings-screen`: сообщение об ошибке при значении объёма вне диапазона теперь называет
  диапазон 10..1000 вместо 10..500.

## Impact

- Код: `core/config.py` (`MAX_MAX_WORDS`).
- Тесты: `tests/unit/test_config.py` (диапазон), `tests/unit/test_answer_settings.py`,
  `tests/unit/test_settings_screen.py`, `tests/e2e/test_settings_flow.py` (сообщение об ошибке
  явно содержит «10..500»).
- Документация: `README.md`, `CLAUDE.md` (упоминания диапазона 10..500 слов).
- Не влияет: нижнюю границу, значение по умолчанию, лимит списка, температуру, формат ответа.
