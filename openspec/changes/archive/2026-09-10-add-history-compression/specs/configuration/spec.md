## MODIFIED Requirements

### Requirement: Переменные переопределения поведения
Следующие переменные SHALL переопределять значения по умолчанию, сохраняя работоспособность
приложения при полном их отсутствии:
- `OPENCODE_API_URL` — адрес эндпоинта (по умолчанию `https://opencode.ai/zen/v1/chat/completions`);
- `TABLETOP_HISTORY_FILE` — путь к файлу истории (по умолчанию `history.json` в корне репозитория);
- `TABLETOP_REQUEST_TIMEOUT` — таймаут HTTP-запроса в секундах (по умолчанию 90);
- `TABLETOP_TYPING_DELAY` — пауза между кадрами анимации печати в секундах (по умолчанию 0.015);
- `TABLETOP_COMPRESS_AFTER` — порог сжатия контекста в сообщениях (по умолчанию 10);
- `TABLETOP_MAX_SESSION_TOKENS` — потолок токенов собираемого запроса сессии (по умолчанию 20000).

#### Scenario: Адрес эндпоинта переопределён
- **WHEN** задана `OPENCODE_API_URL`, указывающая на локальный сервер
- **THEN** все запросы к модели уходят на указанный адрес

#### Scenario: Таймаут переопределён
- **WHEN** задана `TABLETOP_REQUEST_TIMEOUT=1`
- **THEN** HTTP-клиент использует таймаут 1 секунда

#### Scenario: Анимация свёрнута
- **WHEN** задана `TABLETOP_TYPING_DELAY=0`
- **THEN** ответ выводится практически мгновенно, без ощутимой анимации

#### Scenario: Таймаут по умолчанию покрывает медленную генерацию reasoning-моделей
- **WHEN** `TABLETOP_REQUEST_TIMEOUT` не задана и модель генерирует развёрнутый ответ дольше 30 секунд
- **THEN** запрос не обрывается по таймауту раньше 90 секунд

#### Scenario: Лимит истории переопределён
- **WHEN** задана `TABLETOP_HISTORY_LIMIT` (переменная бывшего лимита записей истории)
- **THEN** переменная игнорируется: глубина контекста сессии задаётся порогом сжатия и потолком токенов, а файл истории не ограничен

#### Scenario: Порог сжатия переопределён
- **WHEN** задана `TABLETOP_COMPRESS_AFTER=5`
- **THEN** порог сжатия по умолчанию равен 5 сообщениям

#### Scenario: Потолок токенов переопределён
- **WHEN** задана `TABLETOP_MAX_SESSION_TOKENS=6000`
- **THEN** потолок контекста сессии по умолчанию равен 6000 токенов

### Requirement: Поведенческие константы
Приложение SHALL использовать фиксированные константы: список доступных моделей (`deepseek-v4-flash`, `deepseek-v4-pro`, `kimi-k2.5`, `glm-5.1`, `mimo-v2.5-free`, `kimi-k2.6`, `kimi-k3`) с моделью по умолчанию `deepseek-v4-flash`, температура по умолчанию 0.7 с допустимым диапазоном настройки 0.0..2.0, не более 3 попыток запроса, максимум 2000 символов на вопрос, потолок объёма резюме — 150 слов. Глубина контекста сессии ограничивается не числом записей истории, а сжатием контекста и потолком токенов сессии.

#### Scenario: Список моделей фиксирован
- **WHEN** приложение формирует панель `/models`
- **THEN** список состоит из семи перечисленных моделей, модель по умолчанию — `deepseek-v4-flash`

#### Scenario: Число попыток при таймаутах
- **WHEN** все попытки запроса истекают по таймауту
- **THEN** выполнено не более 3 попыток, после чего сообщается об ошибке

#### Scenario: Границы настроек
- **WHEN** пользователь проверяет допустимые значения на экране настроек
- **THEN** объём ограничен диапазоном 10..1000, лимит списка — 1..10, температура — 0.0..2.0, порог сжатия — 5..50, потолок контекста — 5000..50000
