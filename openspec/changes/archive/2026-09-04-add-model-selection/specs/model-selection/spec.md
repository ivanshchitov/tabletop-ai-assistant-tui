## Purpose

Выбор модели, с которой ассистент отвечает: команда `/models` открывает панель фиксированного списка моделей, выбранная модель применяется ко всем запросам сессии и отображается в статус-баре.

## ADDED Requirements

### Requirement: Команда /models открывает панель выбора модели
Приложение SHALL поддерживать команду `/models`, открывающую интерактивную панель со списком всех доступных моделей. Список SHALL состоять ровно из моделей: `deepseek-v4-flash`, `deepseek-v4-pro`, `kimi-k2.5`, `glm-5.1`, `mimo-v2.5-free`. Управление панелью: ↑/↓ — перемещение курсора, Enter — применить выбранную модель, Esc — отменить выбор. Панель SHALL NOT выполнять API-вызовов: выбор меняет только локальное состояние сессии. Курсор при открытии панели SHALL стоять на текущей модели, а текущая модель SHALL быть визуально помечена в списке. Команда SHALL быть доступна и через ручной ввод с автодополнением, и через панель `/commands` (единый список команд).

#### Scenario: Панель открыта, курсор на текущей модели
- **WHEN** пользователь вводит `/models` при активной модели `deepseek-v4-flash`
- **THEN** открывается панель со списком пяти моделей, курсор стоит на `deepseek-v4-flash`, и модель помечена как текущая

#### Scenario: Выбор модели по Enter
- **WHEN** курсор стоит на `kimi-k2.5` и пользователь нажимает Enter
- **THEN** панель закрывается, `kimi-k2.5` становится активной моделью сессии

#### Scenario: Отмена по Esc
- **WHEN** панель открыта, курсор перемещён на другую модель и пользователь нажимает Esc
- **THEN** панель закрывается, активная модель остаётся прежней, ни одного запроса к API не отправлено

#### Scenario: Запуск из панели /commands
- **WHEN** в панели `/commands` пользователь выбирает строку `/models` и нажимает Enter
- **THEN** открывается панель выбора модели

#### Scenario: Автодополнение команды
- **WHEN** пользователь набирает `/mo` и нажимает Tab
- **THEN** ввод дополняется до `/models`

### Requirement: Выбранная модель применяется ко всем запросам сессии
Выбранная через `/models` модель SHALL использоваться во всех запросах к API до конца сессии: как при ответах на вопросы, так и при прогонах `/logictask`. До явного выбора SHALL использоваться модель `deepseek-v4-flash`. Выбор SHALL действовать только в рамках сессии: после перезапуска приложения активна модель по умолчанию, выбор не сохраняется.

#### Scenario: Вопрос после смены модели
- **WHEN** пользователь выбрал `glm-5.1` и задаёт вопрос
- **THEN** запрос к API содержит модель `glm-5.1`

#### Scenario: /logictask следует выбору
- **WHEN** пользователь выбрал `kimi-k2.5` и запускает `/logictask`
- **THEN** все запросы прогона уходят с моделью `kimi-k2.5`

#### Scenario: Выбор не переживает перезапуск
- **WHEN** пользователь выбрал `mimo-v2.5-free`, завершил приложение и запустил снова
- **THEN** активна модель по умолчанию `deepseek-v4-flash`

### Requirement: Статус-бар показывает активную модель
Статус-бар SHALL отображать имя активной модели рядом с остальными настройками ответа.

#### Scenario: Модель видна после выбора
- **WHEN** пользователь выбрал модель через `/models` и панель закрылась
- **THEN** статус-бар показывает имя выбранной модели
