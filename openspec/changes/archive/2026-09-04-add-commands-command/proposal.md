## Why

Команды перечислены только в статус-баре без описаний, а полный список (включая `/clear` и `/logictask`) приходится помнить наизусть. Нужна обозримая точка входа: просмотр всех команд с кратким описанием и вставка выбранной команды в строку ввода.

## What Changes

- Новая команда `/commands`: интерактивная панель со списком всех команд и краткими описаниями. ↑/↓ — выбор, Enter — **выполнение выбранной команды прямо из панели** (без зависимости от построчного редактирования терминала), Esc — отмена без действий.
- (Ревизия в ходе реализации: исходная идея «вставить команду в поле ввода, подтверждает пользователь» опиралась на предзаполнение буфера readline, которое не поддерживается libedit — readline в macOS-Python. Заменено на прямое выполнение.)
- Статус-бар: в подсказке «Команды:» остаются только `/exit` и `/commands`; полный список — на панели `/commands`.
- Автодополнение по Tab продолжает знать все команды, включая `/commands`.
- Панель по схеме `/settings` и `/logictask`: чистый редьюсер в `ui/commands_screen.py`, в `ui/tui_app.py` — только raw_mode + Live + цикл «клавиша — перерисовка».

### Modified Capabilities

- `terminal-ui`: новый Requirement «Панель команд /commands» (список с описаниями, ↑/↓/Enter/Esc, вставка в поле ввода) и правки существующих требований «Команды и их распознавание» (+`/commands`) и «Статус-бар после каждого шага» (подсказка — только `/exit` и `/commands`).

## Impact

- `ui/tui_app.py`: `COMMANDS` (+`/commands`), константа подсказки статус-бара, диспетчер команд, метод панели команд с прямым запуском выбранной команды.
- Новый модуль `ui/commands_screen.py` (редьюсер, аналог `settings_screen`/`logictask_screen`).
- Тесты: `tests/unit/test_commands_screen.py` (новый), `tests/unit/test_tui_app.py` (статус-бар, диспетчер, выполнение выбора), `tests/e2e/test_commands_flow.py` (новый: панель, выполнение выбранной команды, отмена), снапшоты (`pytest --snapshot-update`).
