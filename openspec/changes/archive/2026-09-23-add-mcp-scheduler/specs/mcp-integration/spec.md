## MODIFIED Requirements

### Requirement: Собственный MCP-сервер проекта над внешним API
Проект SHALL включать собственный MCP-сервер, работающий по транспорту stdio и получающий данные из внешнего публичного API правил настольной ролевой игры. Сервер SHALL объявлять обобщённые инструменты, покрывающие все разделы этого API: перечень доступных разделов, поиск записей внутри раздела, получение полной записи раздела по её идентификатору и сбор данных по разделу с накоплением собранного между вызовами. Сверх справочных инструментов сервер SHALL объявлять инструменты планировщика, позволяющие вызывать его собственные инструменты по расписанию. Перечень разделов SHALL браться у самого API, а не задаваться списком в коде сервера. Адрес внешнего API SHALL переопределяться переменной окружения, чтобы автоматический прогон обращался к локальной заглушке и не выходил в сеть. Отказ внешнего API (недоступность, таймаут, неизвестная запись) SHALL возвращаться вызывающей стороне текстом результата с описанием причины и SHALL NOT завершать серверный процесс.

#### Scenario: Сервер объявляет свои инструменты
- **WHEN** клиент подключается к собственному серверу проекта и запрашивает список инструментов
- **THEN** сервер отдаёт справочные инструменты с именами и описаниями: перечень разделов, поиск по разделу, запись по идентификатору и сбор данных по разделу

#### Scenario: Сервер объявляет инструменты планировщика
- **WHEN** клиент запрашивает список инструментов собственного сервера проекта
- **THEN** среди них есть инструменты постановки задания, перечня заданий, выполнения просроченных заданий и агрегированного отчёта

#### Scenario: Разделы приходят от внешнего API
- **WHEN** вызван инструмент перечня разделов
- **THEN** ответ содержит разделы, перечисленные самим внешним API

#### Scenario: Запись раздела возвращается по идентификатору
- **WHEN** вызван инструмент записи с известным разделом и известным идентификатором
- **THEN** ответ содержит поля записи, как их отдал внешний API

#### Scenario: Поиск по разделу ограничен лимитом
- **WHEN** вызван инструмент поиска с запросом и лимитом записей
- **THEN** ответ содержит не больше указанного числа найденных записей

#### Scenario: Внешний API недоступен
- **WHEN** внешний API не отвечает или возвращает ошибку
- **THEN** результат вызова несёт текст о причине сбоя, а серверный процесс продолжает работать

#### Scenario: Адрес внешнего API переопределён
- **WHEN** задана переменная окружения с адресом внешнего API
- **THEN** сервер обращается по указанному адресу, а адрес по умолчанию не используется

### Requirement: Описание входных параметров инструмента
Каждый инструмент собственного сервера SHALL объявлять схему входных параметров: имя каждого параметра, его тип, назначение, обязательность и — там, где набор значений ограничен, — допустимые значения со значением по умолчанию. Инструменты поиска, записи и сбора данных SHALL принимать необязательный параметр ветки правил с двумя допустимыми значениями и SHALL использовать значение по умолчанию, когда параметр не передан. Аргумент, не удовлетворяющий схеме (отсутствует обязательный параметр, пустое значение, недопустимая ветка правил, лимит вне диапазона), SHALL отклоняться результатом с понятным текстом и SHALL NOT приводить к обращению к внешнему API. Неизвестный раздел SHALL отклоняться результатом, перечисляющим разделы, которые объявляет сам внешний API, и SHALL NOT приводить к запросу записей этого раздела.

#### Scenario: Схема параметров видна клиенту
- **WHEN** клиент запрашивает список инструментов собственного сервера
- **THEN** каждый инструмент несёт схему входных параметров с их именами, типами и признаком обязательности

#### Scenario: Ветка правил по умолчанию
- **WHEN** инструмент вызван без параметра ветки правил
- **THEN** запрос к внешнему API уходит с веткой правил по умолчанию

#### Scenario: Ветка правил задана явно
- **WHEN** инструмент вызван со второй допустимой веткой правил
- **THEN** запрос к внешнему API уходит с указанной веткой

#### Scenario: Обязательный параметр не передан
- **WHEN** инструмент вызван без обязательного параметра
- **THEN** результат вызова несёт текст об отсутствующем параметре, а обращения к внешнему API не происходит

#### Scenario: Недопустимая ветка правил
- **WHEN** инструмент вызван с веткой правил, которой нет среди допустимых
- **THEN** результат вызова несёт текст с допустимыми значениями, а обращения к внешнему API не происходит

#### Scenario: Неизвестный раздел
- **WHEN** инструмент вызван с разделом, которого внешний API не объявляет
- **THEN** результат вызова перечисляет доступные разделы, а записи этого раздела не запрашиваются
