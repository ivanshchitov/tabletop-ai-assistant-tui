## MODIFIED Requirements

### Requirement: Команда /models открывает панель выбора модели
Приложение SHALL поддерживать команду `/models`, открывающую интерактивную панель со списком всех доступных моделей. Список SHALL состоять ровно из моделей: `deepseek-v4.1-flash`, `deepseek-v4-pro`, `glm-5.3-flash`, `mimo-v2.5-free`, `kimi-k3`. Управление панелью: ↑/↓ — перемещение курсора, Enter — применить выбранную модель, Esc — отменить выбор. Панель SHALL NOT выполнять API-вызовов: выбор меняет только локальное состояние сессии. Курсор при открытии панели SHALL стоять на текущей модели, а текущая модель SHALL быть визуально помечена в списке. Команда SHALL быть доступна и через ручной ввод с автодополнением, и через панель `/commands` (единый список команд).

#### Scenario: Панель открыта, курсор на текущей модели
- **WHEN** пользователь вводит `/models` при активной модели `deepseek-v4.1-flash`
- **THEN** открывается панель со списком пяти моделей, курсор стоит на `deepseek-v4.1-flash`, и модель помечена как текущая

#### Scenario: Выбор модели по Enter
- **WHEN** курсор стоит на `kimi-k3` и пользователь нажимает Enter
- **THEN** панель закрывается, `kimi-k3` становится активной моделью сессии

#### Scenario: Отмена по Esc
- **WHEN** панель открыта, курсор перемещён на другую модель и пользователь нажимает Esc
- **THEN** панель закрывается, активная модель остаётся прежней, ни одного запроса к API не отправлено

#### Scenario: Запуск из панели /commands
- **WHEN** в панели `/commands` пользователь выбирает строку `/models` и нажимает Enter
- **THEN** открывается панель выбора модели

#### Scenario: Автодополнение команды
- **WHEN** пользователь набирает `/mo` и нажимает Tab
- **THEN** ввод дополняется до `/models`

#### Scenario: Новые модели тира сравнения доступны
- **WHEN** пользователь открывает `/models`
- **THEN** тир сравнения «слабая — средняя — сильная» закрывают `deepseek-v4.1-flash`, `deepseek-v4-pro` и `kimi-k3`, а моделей, выведенных провайдером из обращения, в списке нет

### Requirement: Таблица цен покрывает все доступные модели
Для каждой модели из списка `/models` SHALL существовать цена входных и выходных токенов (за 1 млн токенов), используемая для расчёта стоимости запроса. Модель без цены в таблице SHALL считаться моделью с неизвестной стоимостью — расчёт стоимости для неё SHALL возвращать отсутствие значения, а не ошибку.

#### Scenario: Цена известна
- **WHEN** запрашивается цена для `deepseek-v4.1-flash`
- **THEN** возвращается пара цен «вход/выход» за 1 млн токенов

#### Scenario: Модель без цены в таблице
- **WHEN** запрашивается цена для модели, отсутствующей в таблице цен
- **THEN** результат — отсутствие значения (не ошибка)

### Requirement: Модель сессии применяется ко всем запросам к API
Выбранная через `/models` модель SHALL использоваться во всех запросах к API до конца сессии: как при ответе на
вопрос, так и во вспомогательных запросах активной стратегии управления контекстом (обновление фактов,
суммаризатор). До явного выбора SHALL использоваться модель `deepseek-v4.1-flash`. Выбор SHALL действовать только
в рамках сессии: после перезапуска приложения активна модель по умолчанию, выбор не сохраняется.

#### Scenario: Вопрос после смены модели
- **WHEN** пользователь выбрал `glm-5.3-flash` и задаёт вопрос
- **THEN** запрос к API содержит модель `glm-5.3-flash`

#### Scenario: Вспомогательный запрос стратегии следует выбору
- **WHEN** пользователь выбрал `kimi-k3`, активна стратегия фактов и он задаёт вопрос
- **THEN** и запрос обновления фактов, и запрос вопроса уходят с моделью `kimi-k3`

#### Scenario: Выбор не переживает перезапуск
- **WHEN** пользователь выбрал `mimo-v2.5-free`, завершил приложение и запустил снова
- **THEN** активна модель по умолчанию `deepseek-v4.1-flash`
