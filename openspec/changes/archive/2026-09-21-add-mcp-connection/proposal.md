## Why

Ассистент умеет разговаривать только с одной моделью и ничего не знает о внешних источниках данных. MCP (Model Context Protocol) — стандартный способ подключить к агенту сторонний сервер с инструментами; первый шаг к этому — научиться поднимать соединение и узнавать, какие инструменты сервер предлагает. Без этого шага любая дальнейшая работа с внешними инструментами упирается в отсутствие транспорта и описания возможностей.

## What Changes

- Агент получает MCP-клиента: поднимает соединение с MCP-сервером по транспорту stdio, выполняет рукопожатие и запрашивает список доступных инструментов.
- Конфигурация сервера задаётся **данными**, а не кодом: реестр описаний серверов (имя, транспорт, команда запуска, аргументы, имена переменных окружения с секретами, описание) и выбранный по умолчанию сервер. Замена сервера — одна запись реестра.
- Переменные окружения переопределяют команду и аргументы запуска сервера, так что тестовый прогон и демонстрация подменяют сервер без правки кода.
- Агент отдаёт снимок отчёта о подключении: имя описания, имя и версия сервера, версия протокола, команда запуска, список инструментов с описаниями, текст ошибки при неудаче. Терминальный слой рисует снимок и не обращается к клиенту напрямую.
- Новая команда `/mcp` печатает этот отчёт; она попадает в панель `/commands` и в автодополнение. Команда не делает ни одного запроса к модели.
- Сбой соединения не завершает сессию: отчёт показывает причину, приглашение ввода возвращается.
- **BREAKING**: минимальная версия Python поднимается с 3.9 до 3.10 — официальный пакет `mcp` не поддерживает 3.9. Матрица CI теряет 3.9.

## Capabilities

### New Capabilities
- `mcp-integration`: подключение к MCP-серверу из агента, реестр описаний серверов, получение списка инструментов и снимок отчёта о подключении.

### Modified Capabilities
- `terminal-ui`: список команд приложения пополняется командой `/mcp`, и появляется требование к содержанию её отчёта.
- `configuration`: добавляются переменные переопределения команды и аргументов запуска MCP-сервера.
- `test-infrastructure`: внешний MCP-сервер не поднимается в автоматическом прогоне — тесты работают против локального фейкового сервера; матрица CI переходит на Python 3.11, 3.12 и 3.13.

## Impact

- Новый модуль `core/mcp_client.py`, новые описания серверов и переменные в `core/config.py`.
- `core/tabletop_agent.py`: снимок отчёта о подключении и новая фаза запроса для индикации.
- `ui/tui_app.py` и `ui/commands_screen.py`: команда `/mcp` и её отчёт.
- Зависимости: добавляется пакет `mcp`; `requirements.txt`, матрица CI и инструкции по запуску в `README.md`/`CLAUDE.md` обновляются под Python 3.10+.
- Тесты: юнит-тесты клиента и отчёта против фейкового stdio-сервера, e2e-сценарий команды `/mcp`, контрактный тест реестра под маркером `network`.
