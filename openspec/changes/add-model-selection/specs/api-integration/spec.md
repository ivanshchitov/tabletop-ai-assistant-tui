## MODIFIED Requirements

### Requirement: Форма запроса к модели
Запрос SHALL выполняться методом POST на эндпоинт chat/completions (по умолчанию `https://opencode.ai/zen/v1/chat/completions`) с заголовком `Authorization: Bearer <ключ>` и JSON-телом, содержащим: модель, выбранную в сессии через `/models` (по умолчанию `deepseek-v4-flash`), два сообщения (system — системное сообщение, user — пользовательский промпт), температуру из активной настройки сессии (по умолчанию 0.7) и `max_tokens`. Других сообщений (вся накопленная история) в запросе быть не должно — история ведётся только для отображения.

#### Scenario: Успешный вопрос
- **WHEN** пользователь выбрал модель через `/models` и задаёт вопрос с активными настройками
- **THEN** к API уходит POST-запрос с выбранной моделью, системным и пользовательским сообщениями, температурой из настройки сессии (по умолчанию 0.7) и max_tokens

#### Scenario: Модель по умолчанию до выбора
- **WHEN** пользователь не открывал `/models` и задаёт вопрос
- **THEN** запрос содержит модель `deepseek-v4-flash`

#### Scenario: История не отправляется
- **WHEN** задан третий вопрос за сессию
- **THEN** запрос содержит ровно два сообщения (system, user), а не накопленную историю

#### Scenario: Температура из настройки
- **WHEN** пользователь установил температуру 1.2 и отправляет вопрос
- **THEN** тело запроса содержит temperature = 1.2
