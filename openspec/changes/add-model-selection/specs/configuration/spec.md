## MODIFIED Requirements

### Requirement: Поведенческие константы
Приложение SHALL использовать фиксированные константы: список доступных моделей (`deepseek-v4-flash`, `deepseek-v4-pro`, `kimi-k2.5`, `glm-5.1`, `mimo-v2.5-free`) с моделью по умолчанию `deepseek-v4-flash`, температура по умолчанию 0.7 с допустимым диапазоном настройки 0.0..2.0, не более 3 попыток запроса, максимум 2000 символов на вопрос, не более 50 записей истории.

#### Scenario: Список моделей фиксирован
- **WHEN** приложение формирует панель `/models`
- **THEN** список состоит из пяти перечисленных моделей, модель по умолчанию — `deepseek-v4-flash`

#### Scenario: Число попыток при таймаутах
- **WHEN** все попытки запроса истекают по таймауту
- **THEN** выполнено не более 3 попыток, после чего сообщается об ошибке

#### Scenario: Границы настроек
- **WHEN** пользователь проверяет допустимые значения на экране настроек
- **THEN** объём ограничен диапазоном 10..500, лимит списка — 1..10, температура — 0.0..2.0
