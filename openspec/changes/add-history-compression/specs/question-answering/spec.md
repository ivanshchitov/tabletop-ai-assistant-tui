## MODIFIED Requirements

### Requirement: Контекст сессии в ответах
Вопрос пользователя SHALL отправляться модели вместе с контекстом предыдущих обменов текущей сессии: одно сообщение-резюме более старых обменов (когда сжатие уже выполнялось) и ходы `user`/`assistant` неотжатых обменов (в границе порога сжатия и потолка токенов сессии), плюс текущий вопрос. Последующие вопросы SHALL интерпретироваться с учётом контекста: уточняющий вопрос («а теперь для пяти игроков?») получает ответ, согласованный с предыдущим обменом, без повторения полного вопроса; сведения из давних обменов, уже свёрнутых в резюме, SHALL оставаться доступными модели через резюме. Первый вопрос сессии и вопрос после `/clear` контекста не имеют.

#### Scenario: Уточняющий вопрос по контексту
- **WHEN** пользователь получил рекомендацию игры и спрашивает «а какие ещё есть с таким же числом игроков?»
- **THEN** ответ относится к предыдущему обмену (модель видит его дословно в контексте), а не требует повторного полного вопроса

#### Scenario: Первый вопрос без контекста
- **WHEN** задан первый вопрос сессии
- **THEN** запрос содержит system и один user-ход

#### Scenario: Сведения давнего обмена доступны через резюме
- **WHEN** ранний обмен уже свёрнут в резюме и пользователь спрашивает о нём («какую игру я просил в начале?»)
- **THEN** ответ согласован с тем ранним обменом (модель получает его содержание из резюме)
