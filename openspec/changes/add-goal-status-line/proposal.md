# Предложение: цель диалога в статус-баре

## Why

Рабочая память задачи (цель и ограничения диалога) уже маршрутизируется из сообщений пользователя и попадает в каждый запрос, но видна только по команде `/memory`. В длинном сценарии (день 25: мини-чат с RAG и памятью задачи, 10–15 сообщений) пользователь не видит, что агент помнит цель, пока явно не спросит отчёт. Статус-бар печатается после каждого шага — это место, где цель должна быть видна постоянно.

## What Changes

- Статус-бар показывает `Цель: «…»` из рабочей памяти задачи, когда цель записана; без записанной цели раскладка статус-бара не меняется (тот же принцип, что у профиля и очереди задач).
- Источник данных — снимок `agent.memory_report()` (граница изоляции: терминал не читает внутренности агента). Значение — пользовательский текст, печатается через `rich.markup.escape`.
- Новых команд, файлов состояния и переменных окружения нет.

## Попутно найденный дефект

Тест с разметкой в цели вскрыл латентный краш: реплика пользователя печаталась как разметка rich
(`Вы: {question}`), поэтому вопрос со строкой «[/dim]» ронял отрисовку. Тот же класс, что уже чинили
для имени профиля и строки `/memory remember`; чинятся обе точки печати пользовательского текста
(реплика и аргумент `/memory goal`).

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `terminal-ui`: требование «Статус-бар после каждого шага» дополняется показом цели диалога из рабочей памяти.

## Impact

- Код: `ui/tui_app.py` (`_status_bar_line`, экранирование реплики и аргумента `/memory goal`).
- Тесты: `tests/unit/test_tui_app.py` (строка цели в статус-баре: показ, отсутствие без цели, замена цели, экранирование разметки в цели и в реплике), `tests/e2e/test_memory_layers.py` (строка цели на отрисованном экране; её отсутствие в последнем статус-баре после `/clear`).
- Документация: `CLAUDE.md`, `README.md`.
- Совместимость: без цели в рабочей памяти экран и снапшоты не меняются.

## Критерии приёмки

- После сообщения, зафиксировавшего цель («моя цель — …»), статус-бар показывает `Цель: «…»` без лишних запросов к модели.
- Без записанной цели строки о цели в статус-баре нет; раскладка прежняя.
- Разметка в тексте цели (`[/dim]` и т.п.) не ломает отрисовку.
- `/clear` очищает рабочую память — строка цели исчезает из статус-бара.
- Демонстрация дня 25: строка цели видна в кадре на протяжении длинного сценария.
