## Context

См. proposal.md. Клиент использует один адрес, `/models` читает конфигурацию, точка входа запускает TUI. llama-server установлен; `models.ini` содержит два пресета и контекст 8192.

## Goals / Non-Goals

**Goals:** общий выбор модели, локальные запросы без облачных секретов, предсказуемое завершение сервера, демо на 2B.

**Non-Goals:** установка llama.cpp, скачивание новых моделей, настройка удалённого сервера, изменение RAG.

## Decisions

- Идентификаторы локальных моделей читаются из секций INI, исключая глобальную `*`. Облачный список остаётся первым. Стоимость локального API равна нулю; затраты электричества не оцениваются.
- Клиент выбирает URL по идентификатору модели; локальные запросы не содержат Authorization. Все вспомогательные запросы используют тот же путь.
- Жизненный цикл сервера оборачивает TUI в точке входа: запуск `server.sh` в отдельной группе процессов, лог в `llama_server/server.log`, ожидание `/health`, остановка в `finally` при `/exit`, EOF, Ctrl+C и ошибке.
- Уже запущенный сервер принимается только после проверки имени процесса слушателя порта через `lsof`/`ps`; при выходе также останавливается по требованию пользователя. Другие процессы на порту не завершаются.
- `TABLETOP_LLAMA_AUTOSTART=0` отключает управление сервером для облачного режима и тестов. Адрес локального API переопределяется `TABLETOP_LOCAL_API_URL`, таймаут запуска — `TABLETOP_LLAMA_START_TIMEOUT`. Управляемый сервер работает только на 127.0.0.1:9999.
- Точка входа создаёт клиент с необязательным ключом; для облака клиент возвращает понятную ошибку, если ключ отсутствует. Прямой TUI сохраняет существующий диалог ввода ключа.
- Демо использует отдельные временные файлы состояния, отключает RAG и инструменты, очищает контекст между вопросами. Проверяет ответы и метрики до записи.

## Risks / Trade-offs

- Загрузка Qwen и генерация на Intel → отдельный таймаут запуска, длинный таймаут в демо и короткие вопросы.
- Ошибка запуска → читаемая диагностика и продолжение с облачными моделями; созданные процессы всегда завершаются.
- Уже работающий сервер принадлежит пользователю → завершение явно согласовано в разговоре; посторонний процесс на порту защищён проверкой имени.
- Маленькая модель может ошибиться → сухой прогон проверяет смысл; ограничения фиксируются в материалах сдачи.

## Migration Plan

История и настройки не мигрируют. Откат — предыдущий тег или отключение автозапуска. Скрипт запуска и модели входят в релиз; GGUF остаются в существующем внешнем кэше.
