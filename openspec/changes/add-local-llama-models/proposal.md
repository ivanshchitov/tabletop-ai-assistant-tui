## Why

День 26 требует запуска локальной LLM и трёх запросов разной сложности. Уже установленные llama.cpp и пресеты Qwen должны работать через существующий интерфейс агента.

## What Changes

- Агент запускает llama-server вместе с собой, ожидает готовности и останавливает сервер при выходе, включая ранее запущенный экземпляр на порту 9999.
- `/models` объединяет облачные модели и локальные модели из `llama_server/models.ini`.
- Локальные запросы направляются на отдельный HTTP-адрес без облачного ключа; облачные сохраняют прежний адрес и авторизацию.
- Демо на Qwen 3.5 2B: три коротких вопроса разной сложности, без RAG и автоматических инструментов.

## Capabilities

### New Capabilities
- `local-llm`: запуск, готовность, остановка и локальные запросы.

### Modified Capabilities
- `model-selection`: общий список облачных и локальных моделей.
- `configuration`: список локальных пресетов и необязательный облачный ключ при запуске.

## Impact

`core/config.py`, `core/api_client.py`, новый `core/llama_server.py`, `tabletop-ai-assistant.py`, `llama_server/server.sh`, `ui/tui_app.py`, `tests/unit/test_local_llm.py`, `tests/unit/test_config.py`, `tests/e2e/harness.py`, `README.md`, `CLAUDE.md`, `.env.example`, `docs/local-llm-questions.md`. Новых Python-зависимостей нет.

Критерии задания (дословно):
- модель запускается локально
- к ней можно обратиться через CLI или HTTP API
- модель отвечает на простой запрос
- минимум 3 запроса разной сложности

Результат: Локальная LLM запущена и отвечает на запросы. Формат: Видео + Код.

Проверка: только затронутые тесты и живой сухой прогон; полный набор исключён по указанию пользователя. Перед записью видео требуется отдельное подтверждение.
