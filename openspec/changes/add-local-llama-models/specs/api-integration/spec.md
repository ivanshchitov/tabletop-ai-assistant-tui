## MODIFIED Requirements

### Requirement: Валидация ключа до запроса
Для облачных моделей ключ SHALL считаться пригодным, только если он непустой и состоит из ASCII-символов (HTTP-заголовки кодируются latin-1, кириллица в ключе — типичная опечатка русской раскладки). Локальные модели SHALL NOT требовать ключа или передавать его в заголовках. При непригодном облачном ключе ошибка SHALL сообщаться до выполнения HTTP-запроса понятным сообщением про раскладку клавиатуры, а не падением на кодировании заголовка.

#### Scenario: Кириллический ключ
- **WHEN** ключ набран в русской раскладке
- **THEN** запрос не отправляется, пользователь видит сообщение о недопустимых символах

#### Scenario: Валидный ключ
- **WHEN** ключ непустой и ASCII
- **THEN** запрос отправляется с этим ключом в заголовке Authorization


### Requirement: Форма запроса — массив сообщений с контекстом сессии
Запрос к облачному API SHALL выполняться методом POST на эндпоинт chat/completions (по умолчанию
`https://opencode.ai/zen/v1/chat/completions`) с заголовком `Authorization: Bearer <ключ>` и JSON-телом,
содержащим: модель, выбранную в сессии через `/models` (по умолчанию `deepseek-v4.1-flash`), массив `messages` —
системное сообщение (собранное из активных настроек ответа), затем память слоёв (см. `memory-model`), затем
контекст по активной стратегии управления контекстом (см. `context-strategies`), затем новый user-ход,
температуру из активной настройки сессии (по умолчанию 0.7) и `max_tokens`. Память слоёв SHALL добавляться одним
системным сообщением с инструкцией работы со слоями, когда рабочая или долговременная память непусты, и SHALL
идти выше ходов диалога, при этом долговременная память SHALL идти в нём перед рабочей. При стратегии фактов перед
ходами SHALL добавляться отдельное системное сообщение с блоком фактов. Глубину контекста задают стратегия и
потолок токенов сессии, а не число записей истории.

#### Scenario: Успешный вопрос
- **WHEN** в облачном режиме пользователь выбрал модель через `/models` и задаёт вопрос с активными настройками
- **THEN** к API уходит POST-запрос с выбранной моделью, массивом сообщений (system, контекст активной стратегии и новый user-ход), температурой из настройки сессии (по умолчанию 0.7) и max_tokens

#### Scenario: Модель по умолчанию до выбора
- **WHEN** в облачном режиме пользователь не открывал `/models` и задаёт вопрос
- **THEN** запрос содержит модель `deepseek-v4.1-flash`

#### Scenario: История сессии отправляется
- **WHEN** в облачном режиме задан третий вопрос за сессию после двух успешных обменов
- **THEN** запрос содержит system, два предыдущих обмена (user и assistant каждый) и новый user-ход

#### Scenario: Глубина контекста ограничена
- **WHEN** в облачном режиме в сессии больше обменов, чем помещается в границу активной стратегии, и задан новый вопрос
- **THEN** массив `messages` содержит только system и те ходы, которые попали в границу стратегии (окно сообщений или потолок токенов)

#### Scenario: Блок фактов в запросе
- **WHEN** в облачном режиме активна стратегия фактов и блок фактов непуст
- **THEN** массив `messages` содержит системное сообщение настроек, затем отдельное системное сообщение с блоком фактов, затем ходы контекста и новый user-ход

#### Scenario: Температура из настройки
- **WHEN** в облачном режиме пользователь установил температуру 1.2 и отправляет вопрос
- **THEN** тело запроса содержит temperature = 1.2

#### Scenario: Память слоёв в запросе
- **WHEN** в облачном режиме рабочая и долговременная память непусты и задан вопрос
- **THEN** массив сообщений содержит системное сообщение памяти выше ходов диалога, в нём долговременная память идёт перед рабочей, а новый ход пользователя остаётся последним

#### Scenario: Пустая память не меняет форму запроса
- **WHEN** в облачном режиме рабочая и долговременная память пусты и задан вопрос
- **THEN** массив сообщений состоит из системного сообщения настроек, контекста активной стратегии и нового хода пользователя, без сообщения памяти

#### Scenario: Память и стратегия фактов вместе
- **WHEN** в облачном режиме активна стратегия фактов, блок фактов и память слоёв непусты
- **THEN** запрос содержит сообщение памяти слоёв, затем отдельное системное сообщение блока фактов, затем ходы диалога и новый ход пользователя

#### Scenario: Совместимость локального шаблона Qwen
- **WHEN** выбрана локальная модель и стек содержит несколько системных сообщений настроек, инвариантов или памяти
- **THEN** запрос направляется на локальный адрес без Authorization, все системные инструкции объединены в один начальный system-блок с сохранением текста и порядка; исходный стек агента не меняется
