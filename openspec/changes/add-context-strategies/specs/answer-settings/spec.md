## MODIFIED Requirements

### Requirement: Семь настроек с диапазонами и значениями по умолчанию
Приложение SHALL поддерживать семь настроек ответа и контекста: формат `free`/`compact`/`json` (по умолчанию
`free`), стратегию управления контекстом `summary`/`sliding_window`/`sticky_facts`/`branching` (по умолчанию
`summary`), максимальный объём ответа в словах в диапазоне 10..1000 (по умолчанию 200), лимит вариантов в
списке-подборке в диапазоне 1..10 (по умолчанию 3), температуру запроса в диапазоне 0.0..2.0 с не более чем
одним знаком после точки (по умолчанию 0.7), порог сжатия контекста в сообщениях в диапазоне 5..50, только целое
(по умолчанию 10) и потолок токенов контекста сессии в диапазоне 5000..50000, только целое (по умолчанию 20000).
Порог сжатия SHALL служить и размером окна для стратегии окна: одно значение, читаемое стратегией по её смыслу.
Настройки SHALL жить в одном неизменяемом снимке, который на чтение доступен главному циклу и экрану настроек.
Изменение стратегии SHALL возвращать новый снимок, не меняя прежний; значение вне списка стратегий SHALL
порождать ошибку, а не молча подменяться значением по умолчанию.

#### Scenario: Стартовые значения
- **WHEN** приложение запускается без изменения настроек
- **THEN** активны формат free, стратегия сжатого резюме, объём 200 слов, лимит списка 3, температура 0.7, порог сжатия 10 сообщений и потолок контекста 20000 токенов

#### Scenario: Допустимые значения
- **WHEN** пользователю показываются настройки
- **THEN** допустимые диапазоны объёма (10..1000), лимита списка (1..10), температуры (0.0..2.0), порога сжатия (5..50) и потолка контекста (5000..50000) отображаются на экране настроек вместе со списком четырёх стратегий

#### Scenario: Верхняя граница объёма поднята для reasoning-моделей
- **WHEN** пользователь устанавливает объём ответа 1000 слов
- **THEN** значение принимается без ошибки, а технический потолок `max_tokens` запроса соответственно растёт (см. `api-integration`)

#### Scenario: Стратегия вне списка
- **WHEN** стратегия задаётся программным вызовом со значением, которого нет среди четырёх стратегий
- **THEN** значение не применяется, прежний снимок настроек остаётся активным, порождается ошибка
