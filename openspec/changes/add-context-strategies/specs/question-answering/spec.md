## MODIFIED Requirements

### Requirement: Контекст сессии в ответах
Вопрос пользователя SHALL отправляться модели вместе с контекстом предыдущих обменов текущей сессии, состав
которого задаёт активная стратегия управления контекстом (см. `context-strategies`): окно последних сообщений,
блок фактов и окно, ходы активной ветки или сжатое резюме с неотжатым хвостом — в границе потолка токенов сессии,
плюс текущий вопрос. Последующие вопросы SHALL интерпретироваться с учётом этого контекста; сведения обменов,
не попавших в контекст активной стратегии, доступны на других стратегиях, потому что ходы остаются в стеке.

#### Scenario: Уточняющий вопрос по контексту
- **WHEN** пользователь получил рекомендацию игры и спрашивает «а какие ещё есть с таким же числом игроков?»
- **THEN** ответ относится к предыдущему обмену (модель видит его дословно в контексте), а не требует повторного полного вопроса

#### Scenario: Первый вопрос без контекста
- **WHEN** задан первый вопрос сессии
- **THEN** запрос содержит system и один user-ход

#### Scenario: Сведения давнего обмена доступны через резюме
- **WHEN** ранний обмен уже свёрнут в резюме и пользователь спрашивает о нём («какую игру я просил в начале?»)
- **THEN** ответ согласован с тем ранним обменом (модель получает его содержание из резюме)

#### Scenario: Сведения давнего обмена доступны на стратегии окна
- **WHEN** ранний обмен выпал из окна, пользователь переключился на стратегию окна с большим размером и спрашивает о нём
- **THEN** обмен снова попадает в запрос дословно, потому что остался в стеке
