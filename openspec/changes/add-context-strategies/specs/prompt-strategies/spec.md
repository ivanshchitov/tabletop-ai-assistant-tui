## REMOVED Requirements

### Requirement: Фиксированная задача прогонов
**Reason**: Команда `/logictask` удаляется целиком — фиксированная задача больше не решается приложением.
**Migration**: Замены нет; для вопросов по настольным играм используется обычный вопрос в главном цикле.

### Requirement: Стратегия 1 — прямой ответ
**Reason**: Техника промптинга «только ответ» существовала лишь внутри прогона фиксированной задачи.
**Migration**: Замены нет.

### Requirement: Стратегия 2 — пошаговое решение
**Reason**: Техника промптинга «решай пошагово» существовала лишь внутри прогона фиксированной задачи.
**Migration**: Замены нет.

### Requirement: Стратегия 3 — промпт от модели
**Reason**: Двухшаговая техника «модель составляет промпт» существовала лишь внутри прогона фиксированной задачи.
**Migration**: Замены нет.

### Requirement: Стратегия 4 — панель экспертов
**Reason**: Техника «панель фиксированных экспертов» существовала лишь внутри прогона фиксированной задачи.
**Migration**: Замены нет.

### Requirement: Выбор стратегии перед прогоном
**Reason**: Панель выбора техники промптинга удаляется вместе с командой прогонов.
**Migration**: Замены нет.

### Requirement: Порядок и оформление вывода
**Reason**: Заголовки и разметка относились только к выводу прогонов.
**Migration**: Замены нет.

### Requirement: Независимость прогонов от настроек ответа
**Reason**: Прогонов больше нет — независимость от настроек ответа поддерживать не для чего.
**Migration**: Замены нет.

### Requirement: Прогоны не попадают в историю
**Reason**: Прогонов больше нет; обычные вопросы, как и прежде, записываются в историю немедленно.
**Migration**: Замены нет.

### Requirement: Ошибка API не прерывает сессию
**Reason**: Требование описывало поведение при ошибке внутри прогона; поведение вопроса при ошибке API описано
в `terminal-ui`.
**Migration**: Замены нет.

### Requirement: Доп.-информация после каждого запроса прогона
**Reason**: Строка метрик под каждым запросом прогона удаляется вместе с прогонами; для вопросов строка метрик
остаётся (см. `question-answering`).
**Migration**: Замены нет.

### Requirement: Прогоны вне стека контекста
**Reason**: Прогонов больше нет — стек сообщений агента формируют только обмены сессии.
**Migration**: Замены нет.
