## ADDED Requirements

### Requirement: Форма запроса — массив сообщений с контекстом сессии
Запрос SHALL выполняться методом POST на эндпоинт chat/completions (по умолчанию `https://opencode.ai/zen/v1/chat/completions`) с заголовком `Authorization: Bearer <ключ>` и JSON-телом, содержащим: модель, выбранную в сессии через `/models` (по умолчанию `deepseek-v4-flash`), массив `messages` — системное сообщение (собранное из активных настроек) и ходы user/assistant накопленной сессии в порядке следования, но не более `HISTORY_LIMIT` (50) последних обменов, температуру из активной настройки сессии (по умолчанию 0.7) и `max_tokens`. Ходы старше границы глубины и материалы прогонов `/logictask` в запросе быть не должны.

#### Scenario: Успешный вопрос
- **WHEN** пользователь выбрал модель через `/models` и задаёт вопрос с активными настройками
- **THEN** к API уходит POST-запрос с выбранной моделью, массивом сообщений (system и ходы сессии), температурой из настройки сессии (по умолчанию 0.7) и max_tokens

#### Scenario: Модель по умолчанию до выбора
- **WHEN** пользователь не открывал `/models` и задаёт вопрос
- **THEN** запрос содержит модель `deepseek-v4-flash`

#### Scenario: История сессии отправляется
- **WHEN** задан третий вопрос за сессию после двух успешных обменов
- **THEN** запрос содержит system, два предыдущих обмена (user и assistant каждый) и новый user-ход

#### Scenario: Глубина контекста ограничена
- **WHEN** в сессии было более 50 обменов и задан новый вопрос
- **THEN** массив `messages` содержит только system и ходы последних 50 обменов

#### Scenario: Температура из настройки
- **WHEN** пользователь установил температуру 1.2 и отправляет вопрос
- **THEN** тело запроса содержит temperature = 1.2

## REMOVED Requirements

### Requirement: Форма запроса к модели
**Reason**: Разворот осознанного решения: запрос из ровно двух сообщений (system + user) без накопленной истории заменён многоходовым запросом — агент хранит стек сообщений сессии и пересылает его модели (задача дня 6 челленджа, «агент как отдельная сущность»).
**Migration**: Заменено требованием «Форма запроса — массив сообщений с контекстом сессии» выше; эндпоинт, авторизация, выбор модели, температура и `max_tokens` переносятся без изменений.
