## ADDED Requirements

### Requirement: Реплей истории не является контекстом модели
Воспроизведение истории при старте SHALL оставаться только показом в журнале главного экрана: загруженные из `history.json` обмены SHALL NOT включаться в стек сообщений агента. Первый вопрос после запуска SHALL отправляться без прошлой переписки — контекст модели живёт в рамках сессии.

#### Scenario: Первый вопрос после рестарта
- **WHEN** приложение запущено с непустой `history.json` и пользователь задаёт первый вопрос
- **THEN** запрос содержит system и один user-ход; сохранённые обмены видны на экране, но модели не отправляются
