## ADDED Requirements

### Requirement: Контекст сессии в ответах
Вопрос пользователя SHALL отправляться модели вместе с предыдущими обменами текущей сессии: модель получает ходы user/assistant всех успешных обменов (в границе глубины контекста) и текущий вопрос. Последующие вопросы SHALL интерпретироваться с учётом контекста: уточняющий вопрос («а теперь для пяти игроков?») получает ответ, согласованный с предыдущим обменом, без повторения полного вопроса. Первый вопрос сессии и вопрос после `/clear` контекста не имеют.

#### Scenario: Уточняющий вопрос по контексту
- **WHEN** пользователь получил рекомендацию игры и спрашивает «а какие ещё есть с таким же числом игроков?»
- **THEN** ответ относится к предыдущему обмену (модель видит его в контексте), а не требует повторного полного вопроса

#### Scenario: Первый вопрос без контекста
- **WHEN** задан первый вопрос сессии
- **THEN** запрос содержит system и один user-ход
