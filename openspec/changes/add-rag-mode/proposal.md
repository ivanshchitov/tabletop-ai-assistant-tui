## Why

Индекс дня 21 уже добавляет найденные фрагменты к ответу, но пользователь не может задать тот же вопрос без них. Для дня 22 нужны два явных режима и одинаковый контрольный набор, чтобы сравнить ответы в демонстрации.

## What Changes

- Добавить переключение `/rules mode on|off` на время сессии; по умолчанию поиск включён.
- В режиме `on` отправлять модели вопрос с релевантными чанками и показывать использованные источники. В режиме `off` не искать чанки и не показывать источники.
- Подготовить 10 контрольных вопросов по локальному корпусу правил. Для каждого зафиксировать ожидаемый ответ и ожидаемые источники.
- В демонстрации задать все 10 вопросов в обоих режимах с чистым контекстом и сравнить качество вне агента. Агент не получает команды сравнения ответов.

Критерии приёмки задания:

- «вопрос → поиск релевантных чанков → объединение с вопросом → запрос к LLM»;
- «ответ модели без RAG» и «ответ модели с RAG»;
- «мини-набор из 10 контрольных вопросов»;
- для каждого вопроса: «ожидание (что должно быть в ответе)» и «какие источники должны быть использованы (если применимо)»;
- «Агент с двумя режимами (с RAG / без RAG) + 10 контрольных вопросов и сравнение качества».
