## Purpose

Внешняя конфигурация приложения: переменные окружения с их значениями по умолчанию, файл-шаблон `.env.example` и поведенческие константы. Переопределения существуют прежде всего для тестовой инфраструктуры (stub-сервер, временный файл истории, свёрнутая анимация).

## Requirements

### Requirement: Загрузка окружения из .env
При старте SHALL загружаться файл `.env` из корня репозитория. Ключ API SHALL браться из переменной `OPENCODE_API_KEY`. Присутствие шаблона `.env.example` в корне SHALL служить контрактом для новых пользователей: файл демонстрирует ровно одну переменную `OPENCODE_API_KEY` со строкой-плейсхолдером в качестве значения.

#### Scenario: Ключ из .env
- **WHEN** в корне репозитория лежит `.env` со строкой `OPENCODE_API_KEY=sk-...`
- **THEN** приложение использует этот ключ без ручного ввода

#### Scenario: Шаблон окружения
- **WHEN** новый пользователь разворачивает репозиторий
- **THEN** файл `.env.example` присутствует и показывает ожидаемую форму `OPENCODE_API_KEY=sk-ваш_ключ`

### Requirement: Переменные переопределения поведения
Следующие переменные SHALL переопределять значения по умолчанию, сохраняя работоспособность приложения при полном их отсутствии:
- `OPENCODE_API_URL` — адрес эндпоинта (по умолчанию `https://opencode.ai/zen/v1/chat/completions`);
- `TABLETOP_HISTORY_FILE` — путь к файлу истории (по умолчанию `history.json` в корне репозитория);
- `TABLETOP_REQUEST_TIMEOUT` — таймаут HTTP-запроса в секундах (по умолчанию 30);
- `TABLETOP_TYPING_DELAY` — пауза между кадрами анимации печати в секундах (по умолчанию 0.015).

#### Scenario: Адрес эндпоинта переопределён
- **WHEN** задана `OPENCODE_API_URL`, указывающая на локальный сервер
- **THEN** все запросы к модели уходят на указанный адрес

#### Scenario: Таймаут переопределён
- **WHEN** задана `TABLETOP_REQUEST_TIMEOUT=1`
- **THEN** HTTP-клиент использует таймаут 1 секунда

#### Scenario: Анимация свёрнута
- **WHEN** задана `TABLETOP_TYPING_DELAY=0`
- **THEN** ответ выводится практически мгновенно, без ощутимой анимации

### Requirement: Поведенческие константы
Приложение SHALL использовать фиксированные константы: модель `deepseek-v4-flash`, температура по умолчанию 0.7 с допустимым диапазоном настройки 0.0..2.0, не более 3 попыток запроса, максимум 2000 символов на вопрос, не более 50 записей истории.

#### Scenario: Число попыток при таймаутах
- **WHEN** все попытки запроса истекают по таймауту
- **THEN** выполнено не более 3 попыток, после чего сообщается об ошибке

#### Scenario: Границы настроек
- **WHEN** пользователь проверяет допустимые значения на экране настроек
- **THEN** объём ограничен диапазоном 10..500, лимит списка — 1..10, температура — 0.0..2.0
