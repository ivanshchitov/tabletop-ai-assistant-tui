# local-rag-embeddings Specification

## Purpose
Использовать настроенную локальную embedding-модель при поиске правил локальными моделями чата, сохраняя совместимость индекса и переключения моделей.

## Requirements

### Requirement: Выбор локальной embedding-модели
Приложение SHALL распознавать embedding-пресеты по `embedding = true` в INI и SHALL исключать их из выбора чата. При выборе локальной модели RAG SHALL использовать настроенный embedding-пресет для документов и запроса через локальный embedding API без облачного ключа. Для облачной модели SHALL сохраняться хеш-поиск.

#### Scenario: Локальная модель
- **WHEN** выбран локальный пресет чата и выполняется поиск RAG
- **THEN** запрос и документы представлены векторами настроенной embedding-модели

#### Scenario: Облачная модель
- **WHEN** после локальной модели выбрана облачная
- **THEN** поиск использует хеш-векторы без embedding-запросов

#### Scenario: Выбор чата
- **WHEN** открывается `/models`
- **THEN** embedding-пресет отсутствует среди моделей чата

### Requirement: Совместимость индекса
Приложение SHALL хранить векторы разных моделей раздельно, SHALL использовать существующие тексты для подготовки недостающих локальных векторов и SHALL NOT смешивать размерности или частично записывать результат неуспешной подготовки.

#### Scenario: Старый индекс
- **WHEN** локальный поиск впервые выполняется по существующему хеш-индексу
- **THEN** локальные векторы создаются из сохранённых чанков, сохраняются и используются повторно без повторного чтения PDF

#### Scenario: RAG отключён или индекс отсутствует
- **WHEN** RAG отключён, индекс отсутствует или приложение только запускается
- **THEN** embedding-запросы не выполняются

### Requirement: Ошибки локальных embeddings
Приложение SHALL показывать понятную ошибку RAG при недоступном сервере, неверном ответе, отсутствующем или неоднозначном embedding-пресете и SHALL NOT молча использовать хеш-поиск вместо локальных embeddings. Предыдущий индекс SHALL сохраняться при неуспешной индексации.

#### Scenario: Ошибка сервера
- **WHEN** сервер возвращает ошибку или некорректный вектор
- **THEN** приложение сообщает об ошибке RAG, продолжает работу и сохраняет предыдущий индекс

#### Scenario: Неоднозначный пресет
- **WHEN** локальный RAG запущен при нуле или нескольких embedding-пресетах
- **THEN** приложение показывает причину ошибки конфигурации без хеш-подмены
